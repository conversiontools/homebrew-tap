# Conversion Tools Homebrew tap

```bash
brew install conversiontools/tap/ctio
```

[ctio](https://github.com/conversiontools/ctio) is the command-line client for the
[Conversion Tools](https://conversiontools.io) API: file conversion, document data
extraction and text to speech from your terminal. macOS (Apple Silicon and Intel) and
Linux x64.

Update with `brew upgrade ctio`.
